# Publications data

`papers.yaml` is the **only publication metadata file you edit**.

The page is assembled as follows:

``` text
data/publications/papers.yaml
            ↓
src/site_components/publications.py
            ↓
publications.qmd
            ↓
docs/publications.html (generated by Quarto)
```

Do not create or maintain `publications.html.md`. It was an intermediate file from the old `keep-md` workflow and duplicates the YAML data.

## Add a paper

Append an item under `papers:`:

``` yaml
- id: short-unique-id
  title: "Paper title"
  authors: [self, "Coauthor, A."]
  year: 2026
  status: working-paper
  type: article
  venue: "Journal name"
  links:
    preprint: "https://example.org/preprint"
    code: "https://github.com/example/repository"
```

Use `self` for your own name. It is expanded using `settings.self_author`.

### Allowed status values

-   `published`
-   `preprint`
-   `working-paper`

### Common type values

-   `article`
-   `educational-resource`
-   `thesis`
-   `chapter`
-   `book`
-   `report`

### Supported links

-   `published`
-   `preprint`
-   `doi`
-   `code`
-   `data`

## Validate before rendering

From the project root:

``` bash
python -m src.site_components.publications data/publications/papers.yaml
```

A valid file prints a short publication count. Invalid or duplicate records produce a descriptive error.
